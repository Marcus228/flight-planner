# flight-planner
Agentic solution for flight planning.

## Manual installation
Before running the agent, make sure that the following dependencies are installed:
- latest version of Python ([download]((https://www.python.org/downloads/)))
- LangGraph ([install](https://docs.langchain.com/oss/python/langgraph/install))
- LangChain ([install](https://docs.langchain.com/oss/python/langchain/install))
- Pydantic ([install](https://pydantic.dev/docs/validation/latest/get-started/install/))
